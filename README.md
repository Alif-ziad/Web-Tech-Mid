# Web Technology Coursework

Collection of introductory **HTML and CSS exercises** completed as web-technology coursework.

## Contents

The repository is organized by topic and task. Examples include:

- Personal/portfolio pages
- Admission and registration forms
- Product catalogues
- Navigation components
- Product cards
- Contact widgets
- Profile cards
- Blog/news layouts
- CSS positioning, overflow, and z-index exercises

## Run

No build process is required. Open an individual `.html` file in a browser. For tasks with a separate stylesheet, keep the accompanying `style.css` in the same project folder.

## Tech

- HTML
- CSS

## Purpose

This repository records foundational web-development practice rather than one production application. Larger projects are documented separately on my GitHub profile.
