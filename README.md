# Web Technology Coursework

Collection of introductory **HTML, CSS, and JavaScript exercises** completed as web-technology coursework.

## What is included

The repository is organized by topic and small practice task rather than as one production application.

- **HTML:** portfolio pages, admission/registration forms, product catalogues, tables, lists, and other markup exercises
- **CSS:** profile cards, navigation, product cards, contact widgets, blog/news layouts, positioning, overflow, and z-index practice
- **JavaScript:** client-side form validation, an image slider, light/dark mode switching, a small student table manager, and a text-analysis exercise
- **Practice tasks:** additional standalone exercises combining the same foundational web concepts

## Repository structure

```text
.
├── HTML/
├── CSS/
├── JS/
├── Practice tasks/
└── README.md
```

Each task keeps its related HTML, stylesheet, script, and image assets together in its own folder.

## Running the exercises

No build process or server is required for the current exercises.

1. Open the folder for a task.
2. Open its `.html` file in a web browser.
3. Keep any accompanying `.css`, `.js`, and image files in the same relative locations.

For example, the JavaScript registration exercise performs browser-side validation for required fields, email format, password confirmation, and numeric phone input, while the student-management exercise dynamically adds and removes table rows in the browser.

## Technologies

- HTML5
- CSS3
- JavaScript (browser/DOM)

## Scope

This is a **coursework/practice repository** documenting foundational frontend exercises. It does not include a backend, database, package-based build system, or production deployment configuration.
